# 岐黄抽卡录 · 网页交互演示版

基于《岐黄抽卡录》微信小程序源码改造的**浏览器静态演示项目**。用于展示游戏交互和前端实现，不是微信小程序本身，也不依赖原 Spring Boot + MySQL 服务。

## 功能

- 丹炉寻珍：投药、蓄能、发光、翻牌揭晓的连续抽卡动画；支持单抽和十连。
- 还原原小程序概率：**SSR 2% / SR 10% / R 38% / N 50%**。
- 十连保底：若十张均为 R/N，随机替换其中一张为 SR，**至少有 1 张 SR 或 SSR**。
- **90 抽 SSR 硬保底**：连续 89 抽未出 SSR 时，第 90 抽强制 SSR；任意 SSR 都会立刻重置计数，单抽和十连共享保底进度。
- 百草图鉴：沿用原项目 82 张中医药文化卡牌数据与 SVG 素材，筛选、搜索、锁定状态与卡牌详情。
- 寻珍手记：本机抽卡历史、收集进度统计、持有数量（含重复）、SSR 保底进度，可手动清空。
- **抽卡结果操作**：结果页可直接再抽一次／再抽十次，点击查看图鉴才会跳转；关闭结果保持在当前页面。
- **视觉强化**：N 白、R 蓝、SR 紫、SSR 金；十连按照本批最高稀有度显示最终揭晓色。
- **卡牌资料**：82 张卡牌对应原小程序的 SVG 卡面；详情包含卡牌标题、题记、文化介绍、编号、类别与真实持有数量。SVG 属于项目内的示意卡面，并非人物或药材的真实照片。
- 使用 `localStorage` 保存浏览器本地数据，**不需要数据库，不与微信小程序账号同步**。
- 适配桌面、平板、手机，支持减少动画偏好。

## 本地查看

下载后解压，双击 `index.html` 即可使用。所有核心功能均为原生 HTML/CSS/JS，无 npm 安装依赖；首次加载字体需联网，离线会自动回退本地字体。

## GitHub Pages 部署

将 `index.html`、`styles.css`、`app.js`、`cards-data.js`、`assets/` 上传到单独仓库根目录；进入仓库 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**，指定 `main`、`/(root)` 并保存。等待 GitHub Pages 部署完成后，访问仓库显示的网页地址。

注意：原微信小程序的前后端源码请保存在另一个仓库或子目录；**不要将包含真实密码的原项目配置文件公开上传**。若 SVG 或素材涉及第三方权利，发布前请核实使用授权。

## 项目说明

演示版保留源小程序稀有度权重及十连保底机制，卡牌资料来自源项目 `data/cards.js`，卡面图来自 `images/cards/*.svg`。新版丹炉动画、响应式布局、结果翻牌、图鉴、历史记录与本地保存为浏览器演示适配开发。文化内容仅用于学习展示，不构成医疗建议。


## V2 丹炉动画改进

点击「单次寻珍」或「十味连炼」，进入**全屏四阶段演出**：投药 → 玄火炼化 → 凝丹蓄力 → 金光／紫光爆发，然后展示逐张翻面的结果卡牌。演出约 4.8 秒，可以点击「跳过动画」。建议在 Chrome / Edge 中使用；若系统开启「减少动态效果」，会尊重系统设置。


## V3 更新与旧存档兼容

1. 结果弹窗关闭后不会自动进入图鉴。可直接再抽 1 次、再抽 10 次或主动查看图鉴。
2. 90 抽 SSR 保底按单张顺序累计，在任意 SSR 出现后清零；十连 SR 保底继续有效。
3. 修复旧版 `owned` 布尔值 `true/false` 被当作数量显示的问题。V3 会自动迁移 `qihuang_demo_v1` 的旧数据，并利用留存的抽卡历史修正数量下限。
4. 旧版仅保留最近 60 次抽卡操作记录，且此前没有保存 SSR 保底进度，因此**无法精确还原被裁剪的旧历史所对应的保底抽数**；V3 会从可用历史估算并从此持续准确累计。
5. 本地存档键为 `qihuang_demo_v3`；所有记录只在当前浏览器／设备保存，不支持多端同步。
6. 目前使用原项目提供的 SVG 卡牌素材；如希望替换为历史人物画像、药材实物图或专业插画，需要逐张确认素材来源与授权。


## V4 插画素材升级

- 以 V3 为基础，替换 `assets/cards/` 中全部 **82 张卡牌 SVG** 为新的可缩放国风插画卡面（人物、药材、方剂、医术四种题材，按卡牌名/稀有度/编号区分）。
- 卡牌数据、抽卡机制、90 抽 SSR 保底、揭晓颜色、结果页按钮、localStorage 数据结构均未调整。
- 静态托管：把本文件夹**内部全部文件**上传到 GitHub 仓库根目录，开启 Settings → Pages → Deploy from a branch → main → /(root)。
- 浏览器缓存：如果仍显示旧版插画，强制刷新（Ctrl+F5），并检查 `assets/cards/1.svg` 等文件是否已更新。
- 插画为本项目使用的程序生成矢量绘制，与医学真实性照片或历史人物肖像无关。
- **未实际推送至用户 GitHub 仓库；在线发布需要仓库授权或用户上传。**
